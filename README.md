# Installation

## Clone the repository

```bash
git clone https://github.com/HIMworks/himworks.github.io.git
```

---

## Open locally

Simply open:

```text
index.html
```

in your preferred web browser.

---

## Deploy to GitHub Pages

1. Push changes to the `main` branch.
2. Open **Repository → Settings → Pages**.
3. Select the **main** branch.
4. Save.
5. GitHub Pages will automatically publish the website.
